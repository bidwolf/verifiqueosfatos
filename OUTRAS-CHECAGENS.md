### Falas que a Lupa checou e este site não registrou

- **Lula:** "a economia não cresce acima de 3% desde 2010" (*Falso*); "acabamos com a fome em 2012" (*Exagerado*); "BR-319, estrada nova" (*Falta contexto*); "pobreza na Argentina chegou a 40% com Milei" (*Falta contexto*); "700 novos mercados" (*Verdadeiro*); "nunca exportamos tanto" (*Verdadeiro*); "33 milhões passavam fome" (*Verdadeiro*).
- **Flávio:** "juros em torno de 14%" (*Verdadeiro*); "marco do saneamento foi nosso" (*Verdadeiro*); "Centro-Oeste é quem mais produz alimento" (*Verdadeiro*); "mais de 80 milhões de inadimplentes" (*Verdadeiro*); "barra de chocolate caiu de 120 g para 80 g por causa da inflação" (*Falso*); "dívida de R$ 11 trilhões" (*Falta contexto*); "Lula deixa o país quebrado" (*Falta contexto*).

Leitura: a amostra deste site deixou de fora, de um lado, as falas de Lula em que a Lupa apontou problema e, de outro, as falas de Flávio que a Lupa confirmou. É o padrão que a seção 3 da metodologia (fila completa + paridade de cobertura) existe para impedir — e ele prejudica a credibilidade do resultado independentemente de qual candidato sai "melhor".

## 4. Como publicar isso no site — `externas.json`

Arquivo estático servido ao lado do `posts.json`, lido pelo front e renderizado abaixo do placar deste site (ou no lugar dele, quando a cobertura for desigual — metodologia, seção 6).

```json
{
  "evento": "Debate TV Globo — 2º turno",
  "data": "2026-10-23",
  "aviso": "Cada agência escolhe suas falas e usa sua própria escala. Os números não se somam nem se comparam diretamente.",
  "fontes": [
    {
      "agencia": "Agência Lupa",
      "ifcn": true,
      "url": "https://www.agencialupa.org/checagem/2026/10/23/ao-vivo-checagem-do-ultimo-debate-entre-lula-e-flavio-bolsonaro-no-segundo-turno/",
      "consultado_em": "2026-10-24T00:25-03:00",
      "atualizado_em": "2026-10-23T23:45-03:00",
      "escala": ["verdadeiro", "falta_contexto", "exagerado", "subestimado", "insustentavel", "falso"],
      "por_candidato": {
        "1": { "checadas": 10, "verdadeiro": 4, "falta_contexto": 2, "exagerado": 1, "subestimado": 1, "falso": 2 },
        "2": { "checadas": 15, "verdadeiro": 4, "falta_contexto": 4, "exagerado": 3, "subestimado": 0, "falso": 4 }
      }
    },
    {
      "agencia": "Aos Fatos",
      "ifcn": true,
      "url": "https://www.aosfatos.org/noticias/checamos-flavio-bolsonaro-lula-debate-globo/",
      "consultado_em": "2026-10-24T00:25-03:00",
      "status": "em_atualizacao"
    },
    {
      "agencia": "Estadão Verifica",
      "ifcn": true,
      "url": "https://www.terra.com.br/noticias/brasil/politica/estadao-verifica-vai-checar-debate-da-globo-ao-vivo-acompanhe,5d669474fb180cd0b8cb2200e7c88ab6w6y8500d.html",
      "consultado_em": "2026-10-24T00:30-03:00",
      "status": "reconsultar"
    },
    {
      "agencia": "g1 Fato ou Fake",
      "ifcn": false,
      "url": "https://www.gazetadopovo.com.br/eleicoes/2026/globo-anuncia-checagem-falas-lula-flavio-durante-debate-nos-canais-digitais/",
      "consultado_em": "2026-10-24T00:30-03:00",
      "status": "reconsultar",
      "escala": ["fato", "nao_e_bem_assim", "fake"]
    }
  ]
}
```

Regras: um item só entra com `url` que abre; `consultado_em` é obrigatório; `status` sinaliza quando a agência ainda não publicou totais; o front nunca converte esses números em percentual.

Rendering sugerido (compatível com o "mínimo mesmo" do README): uma `<section class="externas">` com um `<details>` por agência — nome, hora, tabela de contagens e link — e o aviso em `<p class="aviso">` fixo no topo. Sem bibliotecas, sem fetch adicional além do `externas.json` (que, como o `posts.json`, fica fora do cache do service worker).
